Line MazeGenerator (FROM ECHOSTEP)

A line-maze generator that creates printable and solvable mazes using adjustable dimensions, styles, and path algorithms.

Overview

This tool allows users to generate mazes of various sizes and shapes using intelligent algorithms like Recursive Backtracking ,Prim's Algorithm, Kruskal's Algorithm. It provides control over maze complexity, internal pathways, and solution paths, and also supports exporting the maze as an image, PDF, or code format for integration into applications or games.

Features

  • Adjustable Maze Size: Set width and height (5 to 110 cells).
  • Start Point Selection: Define where the maze begins (Top, Bottom, etc.).
  • Advanced Path Bias Controls:
    • Elitism (E): Controls how direct or shortest the main path is.
    • River (R): Adjusts corridor vs. branch density.
    • River (R): Adjusts corridor vs. branch density.
  • Solution Visualization: Show or hide the correct path through the maze.
  • Export Options: Generate PDF, download maze code, or copy connectivity format for development use.
