Heart Disease Prediction System (ML + Full-Stack App)

A full-stack machine learning application that predicts the probability of heart disease using a Random Forest model, a FastAPI backend, and a modern interactive frontend.

Overview

An end-to-end heart disease prediction platform featuring a trained ML model, REST API, and user-friendly interface for real-time medical risk assessment.

Features

  • Real-time heart disease prediction using a Random Forest classifier.
  • Risk visualization with an interactive donut chart and key factor analysis.
  • CSV-based model retraining directly from the UI.

Tech: HTML, CSS, JavaScript, FastAPI, Python, Scikit-learn
